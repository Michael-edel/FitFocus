Как FitFocus хранит и использует данные

Эта страница описывает фактические типы данных и технические хранилища, используемые приложением FitFocus. Юридические реквизиты оператора и отдельный внешний контакт должны быть заполнены владельцем проекта перед публичным коммерческим запуском.

Дата обновления: 28.06.2026.

Какие данные обрабатываются

  • Аккаунт: идентификатор OAuth, email, имя, аватар, роли, тариф и сессии.
  • Профиль здоровья и питания: цель, вес, рост, возраст, активность, целевой вес, ограничения питания, замеры, давление, пульс, сахар, wearable-снимки.
  • Питание и прогресс: дневник еды, фото еды, фото прогресса, рецепты, меню, списки покупок, отчеты.
  • Push: endpoint подписки, ключи подписки, устройство, браузер, статус доставки.
  • Поддержка: обращения, сообщения, вложения, контакт для ответа, сведения об устройстве и браузере.
  • Администрирование: события админки, сессии администратора и действия по пользователям.

Где хранятся данные

  • Основной источник правды для авторизованного пользователя: Cloudflare D1.
  • Быстрый локальный слой и резервные снимки: localStorage браузера пользователя.
  • Вложения поддержки: встроенно в D1 до лимита или в Cloudflare R2 при настроенном binding `SUPPORT_ATTACHMENTS`.
  • Секреты OAuth, Stripe, Gemini, VAPID и cleanup-хуков должны храниться только в Cloudflare/GitHub secrets, не во фронтенде.

Зачем используются данные

  • Авторизация, синхронизация профиля и восстановление сессии.
  • Расчет питания, ИИ-плана, целей и прогресса.
  • Push-уведомления, если пользователь включил разрешение.
  • Поддержка, диагностика ошибок и администрирование.
  • Оплата и проверка тарифа при настроенном Stripe.

Сторонние сервисы

  • Cloudflare Pages, Pages Functions, D1 и опционально R2.
  • Google OAuth и Apple Sign In для входа.
  • Gemini API для ИИ-функций при настроенном ключе.
  • Stripe для оплаты при настроенных price ids и webhook secret.
  • Push-сервисы браузера/ОС для доставки Web Push.

Права пользователя

В приложении предусмотрены экспорт данных, отключение push на устройстве, выход из аккаунта и удаление аккаунта. Для вопросов по данным пользователь может создать обращение в разделе поддержки FitFocus.

Ограничения

FitFocus не является медицинским изделием. ИИ-рекомендации и расчеты КБЖУ требуют проверки пользователем и не заменяют консультацию врача или специалиста.
