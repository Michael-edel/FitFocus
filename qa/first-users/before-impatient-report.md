# FitFocus baseline: нетерпеливый новый пользователь — повторный валидный прогон
Дата: 2026-10-22. Среда: http://127.0.0.1:4251, локальная SQLite/fixtures. Chrome, новая отдельная вкладка. Код и чужие отчёты не изучались, продукт не менялся.

Результат: первый успех достигнут. Предыдущий технический прогон с append email исключён из продуктовых метрик.

1. Главная: бегло просмотрел информацию, нажал Google профиль. Клик 1.
2. Локальная fixture-форма: предзаполненный адрес оставлен без изменений; нажал Продолжить тестовый вход. Клик 2 (fixture, отдельно от продукта). Вход успешен. Реальные Google и отправка писем не используются.
3. Анкета: уже заполнены вес 70 кг, рост 170 см, возраст 25, мужской пол, похудение, целевой вес 65 кг, умеренная активность 1.6. Как нетерпеливый пользователь принял значения без редактирования. Прокрутил вниз один раз, увидел Создать AI-план. Нажал. Клик 3.
4. Показана AI-инициализация, затем Ваш AI-план. CLOUD: SAVED, AI: ГОТОВ. Дневные KPI: 1800 ккал, 120 Б / 60 Ж / 195 У; цель 65 кг; шаблон питания и правила.
5. Выполнил reload через API (без клика). Открылся Обзор, а не прежний экран плана. Нажал видимый пункт План. Клик 4.
6. Сохранённый план открыт: те же 1800 ккал, 120 Б / 60 Ж / 195 У, цель 65 кг, шаблон дня и правила. CLOUD: IDLE, AI: ГОТОВ. Сохранение после reload подтверждено UI.

Метрики: 4 реальных клика всего (3 продуктовых + 1 fixture); 0 вводов; 1 скролл; 1 reload через API. Первый видимый результат на клике 3, полная проверка сохранения на клике 4. Получение AX и screenshots кликами не считаются.

Затруднения: блокирующих продуктовых ошибок не встретил, желания уйти не возникло. Кнопка создания ниже первого экрана, потребовалась одна прокрутка. После reload экран переключился на Обзор, сохранённый план пришлось открыть одним кликом; это лёгкое трение, не ошибка. Предустановленные значения ускорили путь, но пользователь мог принять чуждые ему параметры; значения не редактировались.

Вернулся бы: да. План появился быстро, дневные цели понятны и сохранились после reload.

Снимки: JPEG image-результаты Browser CUA: анкета до прокрутки; анкета с кнопкой; сохранённый план после reload. Файлы JPEG НЕ сохранены даже в разрешённый cwd: документированный Browser CUA API возвращает bytes/image, но не предоставляет filesystem writer/путь выгрузки, а перенос bytes в shell недоступен. Пути изображений не выдумывались. Родитель может использовать image-результаты разговора.

Ограничения: фиксированные локальные auth/AI fixtures; реальная авторизация Google, качество генерации AI, production cloud и платежи не проверены. AX скрывает email, поэтому адрес не прочитан повторно; использовано предзаполненное корректное значение согласно инструкции повторного прогона. Существующие рабочие вкладки, глобальные настройки и пользовательские данные не затронуты.
