# Приёмка владельцем и сыном

Статус: сценарий подготовлен, люди его ещё не проходили. AI-роли не заменяют
результаты этой проверки. Запускать только в подтверждённой изолированной среде
с искусственными данными; рабочий сайт и рабочую DB для этого не использовать.
Записать URL, commit/build id, браузер, ширину, сетевой режим и начальное состояние.
Для iPhone отдельно указать физическое устройство или эмуляцию. Нельзя называть
обычную связь медленным3G без реально проверенного ограничения.

## Подготовка наблюдателя

Подготовьте два разных тестовых аккаунта и карточки выдуманной семьи из трёх
человек. В карточках дайте только необходимые факты: имена, взрослый/ребёнок,
разные пожелания и явно известные ограничения. Не используйте настоящие
медицинские данные. Один родственник должен оставаться профилем без аккаунта.
Не объясняйте названия разделов и расположение кнопок. Вход/регистрацию замерьте
отдельно; семейный таймер начинается с первого действия после входа.

## Карточка организатора

«Вы планируете еду для семьи из карточки. Получите общий план хотя бы на сегодня,
понятные порции каждому и список того, что купить. Затем замените ужин и измените
участие одного человека. Убедитесь, что после обновления страницы результат
остался. Передайте второму участнику возможность пользоваться общей семьёй».

Не продолжайте за человека, решившего уйти. Если требуется помощь, сначала
зафиксируйте затруднение и решение; дальнейшее прохождение отмечайте как
выполненное с подсказкой, отдельно от самостоятельного результата.

## Карточка участника

«Присоединитесь к семье по полученному приглашению. Разберитесь, что сегодня
готовят и что осталось купить. Отметьте покупку и повторно откройте приложение.
Посмотрите, что вы можете изменить и какие личные сведения другого человека
доступны. Скажите, что ожидали увидеть и чему не доверяете».

Организатор затем самостоятельно проверяет, появилось ли изменение покупки
в его аккаунте. Локальное сохранение, серверное подтверждение и видимость
второму аккаунту фиксируются раздельно.

## Протокол без подсказок

| Этап | Время от старта | Клики до результата | Что произошло / затруднение | Скриншот |
|---|---|---|---|---|
| Первое меню с порциями и покупками | | | | |
| Замена ужина | | | | |
| Изменение участия | | | | |
| Повторное открытие | | | | |
| Общая покупка видна второму аккаунту | | | | |

Клик/тап считаются отдельно от ввода и прокрутки; общий счёт действий хранится
отдельно. Первым семейным результатом не считать регистрацию, анкету или
персональный план. На затруднении записать ожидание, фактический результат,
действие и скриншот без email, токенов и реальных персональных данных.

После завершения каждый отвечает своими словами:

1. Было ли понятно следующее действие?
2. Доверяете ли порциям, ограничениям и сохранению? Почему?
3. Вернулись бы завтра? Почему?
4. Что мешало больше всего?

Итоги сохранять в отдельном `qa/first-users/human/` с указанием версии и условий.
До получения этих протоколов не заявлять человеческую приёмку или удержание.
