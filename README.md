# FitFocus

Эта ветка `fix/profile-cas-rollout` — промежуточная серверная версия до
миграции 0020. Код CAS: `dde4c71`, база: `14ca638`. Назначение, локальные
проверки и порядок перехода: [инструкция выпуска](docs/profile-cas-rollout.md).
Остальные описания ниже унаследованы из базы; итоговая проекция находится
в ветке `fix/durable-outbox`. Staging и выпуск этой версии ещё не выполнены.

FitFocus — PWA для питания, привычек и прогресса: дневник, анализ еды,
персональный план, рецепты, семейное меню и список покупок. Есть вход через
Google/Apple, push, поддержка и административные функции. Доступность
внешних интеграций зависит от настройки среды.

Обновлено: 14.10.2026. Текущий этап — стабилизация сохранения данных,
синхронизации и выпуска. Полный перечень функций: [PRODUCT.md](PRODUCT.md).

## Локальный запуск

Среда CI: Node.js 24, Python 3.12. Из корня репозитория:

```text
npm ci
npm run dev
```

Vite запускает клиент на `http://localhost:5173` и проксирует `/api` на
`http://localhost:8788`. Для входа и серверных функций требуется настроенный
backend; порядок и ограничения описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Состояние этой ветки

Здесь открыта промежуточная ветка `fix/profile-cas-rollout`: код подготовки
profile CAS добавлен в `dde4c71` на базе `14ca638`; последующие изменения
фиксировали порядок перехода и результаты проверок в документации. Эта версия
нужна для безопасного перехода серверной базы с миграции 0019 на 0020. Она не
является итоговой серверной проекцией из `fix/durable-outbox`. Подробный порядок,
локальные результаты и оставшиеся
условия выпуска приведены в [инструкции перехода](docs/profile-cas-rollout.md).

Точные границы проверенных компонентов и приоритеты всего проекта находятся
в [статусе](docs/project-status.md) и [TASKS](TASKS.md). Контракт legacy-импорта
и согласованные правила нормализатора — в
[docs/legacy-migration.md](docs/legacy-migration.md) и [ADR-005](docs/adr/ADR-005-durable-outbox.md).
История проверок с привязкой к SHA сохранена в
[журнале стабилизации](docs/stabilization-progress.md).

Для этой ветки отдельно остаются подтверждение CI опубликованного HEAD,
проверка старого и нового bundles на staging, совместимый откат и интеграция
через защищённую `main`. Локальная проверка перехода не подтверждает эти этапы.

Предыдущее подробное описание и старые результаты проверок сохранены
в [архиве README](docs/history/README-2026-08-29.md).

[на ревизии 93f90c0](https://github.com/Michael-edel/FitFocus/blob/93f90c07646ca8aac4a9dcec9ac9e19b67971038/README.md).
