# FitFocus

FitFocus — PWA для питания, привычек и прогресса: дневник, анализ еды,
персональный план, рецепты, семейное меню и список покупок. Есть вход через
Google/Apple, push, поддержка и административные функции. Доступность
внешних интеграций зависит от настройки среды.

Обновлено: 09.10.2026. Текущий этап — стабилизация сохранения данных,
синхронизации и выпуска. Полный перечень функций: [PRODUCT.md](PRODUCT.md).

## Локальный запуск

Среда CI: Node.js 24, Python 3.12. Из корня репозитория:

```text
npm ci
npm run dev
```

Vite запускает клиент на `http://localhost:5173` и проксирует `/api` на
`http://localhost:8788`. Для входа и серверных функций требуется настроенный
backend; порядок и ограничения описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Что подтверждено

Описание архитектуры закреплено за `810adb1` из
[PR #90](https://github.com/Michael-edel/FitFocus/pull/90).
Последующие исправления CI и проверенные компоненты P0.8 перечислены
[в журнале](docs/stabilization-progress.md) с отдельными ревизиями.
Компонент импорта legacy на `51a789c` прошёл 649 unit-тестов и полный CI;
[граница этого снимка](docs/outbox-implementation.md). Следующее изменение
подключает шесть ключей приложения к атомарному repository и защищённой
загрузке из облака: [текущий клиент](docs/runtime-state.md). На совместной
локальной реализации прошли 697 unit-тестов и 33 браузерных сценария;
GitHub CI проверяется отдельно на точном HEAD. HTTP sender и весь P0.8
ещё не завершены.
Серверный компонент P0.7 проверен отдельно на `237f862` в PR #94:
532 unit-теста и CI прошли; [контракт и ограничения](docs/state-generations.md).
Серверная ветка объединена с клиентской коммитом `93f90c0`; это подтверждает
зависимость кода, а не staging или выпуск. Условия и результаты совместной
проверки перечислены в журнале.
На дату проверки PR #90 и [PR #92](https://github.com/Michael-edel/FitFocus/pull/92)
ещё не слиты в защищённую `main`. Поэтому состояние этих веток не считается
состоянием выпущенного приложения, а P0 остаётся открытым.

Предыдущее подробное описание и старые результаты проверок сохранены
в [архиве README](docs/history/README-2026-08-29.md).
Дополнения прежнего README интеграционной ветки доступны
[на ревизии 93f90c0](https://github.com/Michael-edel/FitFocus/blob/93f90c07646ca8aac4a9dcec9ac9e19b67971038/README.md).
