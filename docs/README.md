# Документация FitFocus

Обновлено: 09.10.2026.

## Область и достоверность

Фактическое описание сверено с ревизией
[`810adb11b01447114de9f240c6e2d520f747470b`](https://github.com/Michael-edel/FitFocus/tree/810adb11b01447114de9f240c6e2d520f747470b)
в [PR #90](https://github.com/Michael-edel/FitFocus/pull/90), ветка
`fix/dependency-audit`. На момент сверки GitHub `main` —
`c939ae6f3dbdb802478ea8a305b180eefb0b90f8`; между ними 250 коммитов.
Описание этой интеграционной ревизии не подтверждает её слияние или deploy.

Ссылки на исходники закреплены за проверенным SHA. Документы можно
интегрировать отдельным PR, но нельзя автоматически считать перечисленные
модули уже присутствующими в GitHub `main`. При интеграции кода снимок нужно
обновить по фактическому diff и повторным проверкам.

Пакет создаёт документацию. Он не реализует P0, не подтверждает staging,
production-интеграции или отсутствие секретов. Результаты прошлых тестов
в старом README относятся к указанным там датам и ревизиям.

## Поддержание документов

Меняя код, обновлять соответствующий контракт, TASKS и сведения о проверке.
Готовый пункт закрывается со ссылкой на commit/PR и результаты тестов.
Изменение решения получает новую запись, сохраняющую причину прежнего выбора.
Секреты, токены и пользовательские данные в Markdown не сохраняются.
